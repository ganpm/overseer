Overseer is a simple browser idle game based on automation games built with React and Rust WebAssembly.

## Tech Stack

Frontend/UI: [typescript](https://www.typescriptlang.org/), [react](https://react.dev/), [tailwindcss](https://tailwindcss.com/), [vite](https://vite.dev/), [shadcn/ui](https://ui.shadcn.com/)

Game data validation: [zod](https://zod.dev/)

Game engine: [rust](https://rust-lang.org/), [wasm-bindgen](https://crates.io/crates/wasm-bindgen), [serde](https://crates.io/crates/serde), [tsify](https://crates.io/crates/tsify)
